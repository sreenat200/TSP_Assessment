# Tolaram Technical Assessment – Traveling Salesman Problem (TSP)

Balanced route assignment + TSP optimization for ~3950+ shops across Lagos to 41 agents.

## Project Overview
- **Data**: Lat/Long + shop details from TSP1.xlsx
- **Clustering**: Spatial balanced assignment to agents
- **Optimization**: Nearest Neighbor + 2-Opt for each agent's route
- **Outputs**: Excel with routes, metrics CSV, high-quality visualization
